Запуск за минуту

Нужен только Python 3.10+ и токен от @BotFather. API-ключ LLM — необязателен: без него бот работает офлайн.

# 1. клонировать и подготовить окружение
git clone https://github.com/j0k/21day_system.git
cd 21day_system
copy .env.example .env
# 2. вписать в .env токен и (по желанию) ключ LLM
# 3. запустить бота
python bot.py
01 · SETUP

Клонировать

Стандартная библиотека и matplotlib — внешних сервисов не нужно.

02 · CONFIG

Вписать токен

Один TELEGRAM_BOT_TOKEN в .env. Ключ LLM — по желанию.

03 · RUN

Запустить

python bot.py — и нажать Start в Telegram.

FAQ

Частые вопросы

Нужен ли API-ключ, чтобы пользоваться ботом?

Нет. Без ключа бот работает в офлайн-режиме: совет дня формируется по правилам, без обращений в сеть. Ключ (OpenAI-совместимый, например RouterAI) добавляет «умные» ответы и чат с моделью.

Где хранятся данные?

В одном файле SQLite — data/21day.sqlite3: пользователи, отметки по дням и журнал событий. Ничего лишнего наружу не уходит.

Можно ли собрать свою 21-дневную систему?

Да. Есть отдельный гайд HOWTO_MAKE_SELF_21_SYS.md: система описывается данными в systems.py, а придумать и оформить её можно прямо в диалоге с LLM.

Что такое индикаторы Welles Wilder здесь?

Это RSI, ADX и ATR — классические индикаторы Дж. Уэллса Уайлдера, применённые к последовательности отметок 0/1. Они показывают импульс, силу тренда и волатильность темпа прохождения практики.

Есть ли мобильное приложение?

Нет — и не нужно: весь интерфейс живёт в Telegram. Отдельно запланировано десктопное приложение-пульт (трей) для управления ботом и прогрессом с рабочего стола.
