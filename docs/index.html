Прогресс, который видно

Бот не просто считает дни — он показывает состояние практики теми же инструментами, что используют трейдеры и пилоты.

  • RSI-прогресс — импульс: успехи против пропусков
  • ADX-тренд — сила и устойчивость серии
  • ATR-темп — насколько рвано идут отметки
  • пейс 7 дней — доля выполнения за неделю
  • прогноз финиша — ожидаемый день завершения

Запуск за минуту

Нужен только Python 3.10+ и токен от @BotFather. API-ключ LLM — необязателен.

# 1. склонировать и настроить окружение
git clone https://github.com/j0k/21day_system.git
cd 21day_system
copy .env.example .env
# 2. вписать в .env токен и (по желанию) ключ LLM
# 3. запустить бота
python bot.py
