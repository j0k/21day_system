# 21day_system

Telegram-бот трёх 21-дневных систем микро-практики.

Проект: <https://github.com/j0k/21day_system>

## Что это

Три программы по 21 дню, каждая — по 3–5–7 минут в день, от простого к
сложному. Навык растёт косвенно: важно не качество отдельного действия,
а повторяемость.

| Система | О чём |
|---|---|
| 🧠 21 день · микро-практика | навыки: Prolog-мышление, роботы, RSI, edge, Welles Wilder |
| 🗓 21 день · режим дня и дисциплина | среда, якоря, ритм, фокус, восстановление |
| 🌙 Ночной ритм · 21 день сна | свет, среда спальни, ритм, расслабление |

## Возможности

* Первый, кто пишет боту, **выбирает систему кнопкой** в Telegram.
* Бот **пишет прогресс**: отметки по дням, заметки, серии.
* **Индикаторы прогресса видны всегда** — сделаны по мотивам индикаторов
  J. Welles Wilder Jr.:
  * `RSI-прогресс` — импульс (успехи против пропусков);
  * `ADX-тренд` — сила серии;
  * `ATR-темп` — волатильность темпа;
  * `пейс 7 дней` и `прогноз финиша`.
* Бот присылает **график прогресса**: `/chart` — «трейдерский» (тёмный, с
  панелями RSI/ADX/темпа), `/chart styled` — стилизованный (пастель) или
  `/chart radar` — **радар прогресса в духе TCAS** (метки целевых показателей
  сближаются с центром по мере приближения к цели).
* **Все результаты в одном файле SQLite3**: `data/21day.sqlite3`
  (таблицы `users`, `progress`, `log`).
* **Участники и лидерборд**: на экране выбора системы видно число
  участников и топ лидеров; есть отдельные экраны «👥 Участники» и
  «🏆 Лидеры» (с фильтром по системе).
* **Профиль и приватность**: в своём профиле можно сделать себя публичным
  (`/profile`). Пока профиль приватный, в таблице лидеров ты значишься как
  **Private User**.
* **Админка** (`/admin`, только для ID из `ADMIN_IDS`): сводка, список
  пользователей, карточка пользователя (сброс прогресса, публичность,
  удаление), журнал событий, рассылка.
* **Чат с LLM о функционале** (`/dev`, только админ): свободный диалог с
  моделью про фичи бота — идеи, решения, фрагменты кода. Бот передаёт
  модели краткий контекст проекта (файлы, что уже есть) и помнит 12 реплик.
* **Markdown-рендер**: ответы LLM (и совет дня, и `/dev`) показываются как
  форматированный текст — жирный, курсив, `код`, блоки кода, списки, ссылки
  (модуль `md.py`, без сторонних библиотек).

## Запуск

```bat
cd D:\pm\soft\21day_system
copy .env.example .env
rem впиши TELEGRAM_BOT_TOKEN от @BotFather
python bot.py
```

Внешних зависимостей нет — только стандартная библиотека Python плюс
`matplotlib` для графиков.

## Конфигурация

Переменные окружения или файл `.env`:

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от @BotFather |
| `OPENAI_API_KEY` | нет | API-ключ OpenAI напрямую |
| `ROUTERAI_API_KEY` | нет | API-ключ RouterAI (base_url подставляется сам) |
| `LLM_API_KEY` | нет | ключ любого OpenAI-совместимого сервиса |
| `OPENAI_BASE_URL` | нет | явное переопределение базового URL |
| `OPENAI_MODEL` | нет | модель (по умолчанию `gpt-4o-mini`) |

Ключ можно задать **и в `.env`, и через переменные окружения Windows** —
бот берёт первое непустое из `OPENAI_API_KEY` / `ROUTERAI_API_KEY` /
`LLM_API_KEY`. Если задан `ROUTERAI_API_KEY`, базовый URL автоматически
становится `https://routerai.ru/api/v1`, а модель — с префиксом провайдера
(`openai/gpt-4o-mini`); модель можно переопределить (`ROUTERAI_MODEL`).

Пример настройки через переменную окружения:

```powershell
[Environment]::SetEnvironmentVariable("ROUTERAI_API_KEY", "ваш_ключ", "User")
# затем перезапустите терминал и запустите: python bot.py
```

**Без API-ключа бот полностью работает** — советник отвечает офлайн,
сетевые вызовы не делаются.

## Команды

| Команда | Действие |
|---|---|
| `/start` | выбрать систему (кнопкой) |
| `/today` | текущий день |
| `/progress` | прогресс и индикаторы |
| `/chart [styled\|radar]` | график прогресса |
| `/systems` | сменить систему |
| `/users` | участники |
| `/board` | таблица лидеров |
| `/profile` | профиль и видимость (публичный/приватный) |
| `/admin` | админ-панель (только администратор) |
| `/dev` | чат с LLM о функционале (только администратор) |
| `/cancel` | отменить ввод заметки |
| `/help` | справка |

| `storage.py` | SQLite-хранилище |

| `llm.py` | необязательный LLM-советник |
