# 21day_system

> Telegram-бот трёх 21-дневных систем микро-практики: **навыки**, **режим дня** и **сон**.

[![Docs](https://img.shields.io/badge/docs-readme%20%2B%20setup-1f8f8a)](SETUP.md)

**21day_system** — это бот, который помогает пройти короткую программу из 21 дня: 3–7 минут в день, от простого к сложному. Смысл не в качестве отдельного действия, а в **повторяемости** — навык растёт косвенно, как капитал на счёте.

Бот сам ведёт счёт, показывает прогресс **индикаторами в стиле Welles Wilder**, рисует графики и радар, сравнивает участников в лидерборде и умеет работать **полностью офлайн** — без API-ключа.

## Три системы

Первый запуск — выбор одной из трёх кнопкой. Выбор можно сменить в любой момент.

| Система | Что развивает | Ключевые темы |
|---|---|---|
| 🧠 **21 день · микро-практика** | косвенную прокачку навыков | Prolog-мышление, роботы, RSI, edge, Welles Wilder |
| 🗓 **21 день · режим дня и дисциплина** | устойчивый ритм и фокус | среда, якоря, приоритеты, восстановление |
| 🌙 **Ночной ритм · 21 день сна** | качество сна | свет, среда спальни, ритуалы, расслабление |

Каждая система разбита на три недели: **замечать → держать ритм → закреплять**.

## Возможности

- **Выбор системы кнопкой** в Telegram, смена в любой момент.
- **Отметки по дням** — выполнено / пропущено, плюс короткие заметки.
- **Индикаторы прогресса видны всегда** — RSI / ADX / ATR по мотивам Welles Wilder, пейс за 7 дней и прогноз финиша.
- **Три графика**:
  - `📈` трейдерский — тёмная тема, линия прогресса + панели RSI/ADX/темпа;
  - `🎨` стилизованный — светлая пастельная тема;
  - `📡` **радар TCAS** — метки целевых показателей сближаются с центром по мере приближения к цели.
- **Участники и лидерборд** — счётчик участников и топ‑3 прямо на экране выбора системы; отдельные экраны «👥 Участники» и «🏆 Лидеры» с фильтром по системе.
- **Профиль и приватность** — можно стать **публичным** (имя видно в лидерборде) или остаться **приватным** (`Private User`).
- **Админка** — сводка, список пользователей, карточка пользователя, журнал событий, рассылка.
- **Чат с LLM о функционале** — свободный диалог с моделью про фичи бота.
- **Markdown-рендер** ответов LLM: жирный, курсив, `код`, блоки кода, списки, ссылки.
- **Работает без API-ключа** — офлайн-советник по правилам, без сетевых вызовов.

## Индикаторы в стиле Welles Wilder

J. Welles Wilder Jr. придумал RSI, ATR и ADX. Те же идеи здесь применены к **ряду отметок 0/1** (а не к накопленному прогрессу — иначе индикаторы всегда были бы «100»).

| Индикатор | Что показывает |
|---|---|
| `RSI-прогресс` | импульс: успехи против пропусков |
| `ADX-тренд` | силу и устойчивость серии |
| `ATR-темп` | волатильность темпа (насколько рвано идут отметки) |
| `пейс 7 дней` | доля выполнения за последнюю неделю |
| `прогноз финиша` | ожидаемый день завершения по среднему темпу |

Пример блока, который видно в каждом экране:

```text
📈 Индикаторы прогресса (стиль Welles Wilder)
выполнено 14/21 · 67%
RSI-прогресс  🟡  58.0  ██████░░░░
ADX-тренд        41.2  ████░░░░░░  (тренд формируется)
ATR-темп         0.31  (волатильность)
пейс 7 дней      71%   ███████░░░
прогноз финиша: день ~21
```

## Быстрый старт

```bat
git clone https://github.com/j0k/21day_system.git
cd 21day_system
copy .env.example .env
rem впиши в .env свой TELEGRAM_BOT_TOKEN от @BotFather
```

## Конфигурация

Все настройки читаются из окружения или файла **`.env`** рядом с `bot.py`.

| Переменная | Обяз. | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | токен от [@BotFather](https://t.me/BotFather) |
| `OPENAI_API_KEY` | — | ключ OpenAI напрямую |
| `ROUTERAI_API_KEY` | — | ключ RouterAI (base URL подставляется сам) |
| `LLM_API_KEY` | — | ключ любого OpenAI-совместимого сервиса |
| `OPENAI_BASE_URL` | — | явное переопределение базового URL |
| `OPENAI_MODEL` | — | модель (по умолчанию `gpt-4o-mini`) |
| `ADMIN_IDS` | — | Telegram user_id админов через запятую |
| `DATA_DIR` | — | папка с базой (по умолчанию `./data`) |
| `POLL_TIMEOUT` | — | таймаут long-polling, сек (по умолчанию `30`) |

Бот берёт **первый непустой** ключ из `OPENAI_API_KEY` / `ROUTERAI_API_KEY` / `LLM_API_KEY`. Если задан `ROUTERAI_API_KEY`, базовый URL и префикс модели подставляются автоматически.

```powershell
# можно и через переменные окружения Windows
[Environment]::SetEnvironmentVariable("ROUTERAI_API_KEY", "ваш_ключ", "User")
```

**Без API-ключа бот полностью рабочий** — советник отвечает офлайн.

## Админка и чат с LLM

Доступ по списку `ADMIN_IDS` (env) или значению по умолчанию.

### 🛠 Админка (`/admin`)

| Раздел | Что делает |
|---|---|
| 📊 Сводка | пользователи, публичные, отметки, события, разбивка по системам |
| 👥 Пользователи | список с пагинацией: видимость, система, прогресс |
| 👤 Карточка | прогресс человека + **сбросить / публичность / удалить** |
| 🕓 Журнал | последние 20 событий |
| 📣 Рассылка | сообщение всем пользователям |
| 🔎 Найти | по username, имени или id |

### 💬 Чат с LLM (`/dev`)

Свободный диалог с моделью про функционал проекта: идеи, решения, фрагменты кода. Бот подмешивает **краткий контекст проекта** и помнит последние **12 реплик**. Персона настроена на стек проекта: только стандартная библиотека Python и matplotlib.

## Структура проекта

```text
21day_system/
├── bot.py            # точка входа: экраны, клавиатуры, обработчики, long-polling
├── config.py         # конфигурация и минимальный .env-парсер
├── systems.py        # данные трёх систем (21 день × 3 недели)
├── storage.py        # SQLite-хранилище (users, progress, log) + миграции
├── indicators.py     # RSI / ADX / ATR в стиле Welles Wilder
├── graph.py          # графики: трейдерский и стилизованный
├── radar.py          # радар прогресса в духе TCAS
├── llm.py            # необязательный LLM-советник и чат о функционале
├── md.py             # Markdown → Telegram-HTML
├── data/             # 21day.sqlite3 (gitignored)
├── selftest.py           # офлайн-прогон экранов
├── selftest_all.py       # прогон трёх систем + графики
├── selftest_config.py    # проверка конфигурации под разные ключи
├── demo_progress.py      # демонстрация вывода прогресса
├── .env.example
└── README.md / SETUP.md
```

### Хранилище

Всё лежит в одном файле `data/21day.sqlite3`:

| Таблица | Назначение |
|---|---|
| `users` | кто пишет боту, выбранная система, приватность, `started_at`, `last_seen` |
| `progress` | результат по каждому дню: `done`, `minutes`, `note` |
| `log` | журнал событий (кто что нажал) |
